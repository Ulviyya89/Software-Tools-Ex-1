# Software Tools Exercise 1

A small Python project for practicing Git commits, branches, merging, and GitHub collaboration.

## Run

```powershell
python app.py
```

Expected output:

```text
Hello AI/ML World!
Adding new feature
Feature branch code
Change made on GitHub
```

## Review the Git history

```powershell
git log --oneline --graph --decorate --all
git status
```

The history demonstrates three initial commits, a feature branch merged into `main`, a change made remotely on GitHub and pulled locally, and a README added to resolve a GitHub issue.

The remote edit was made through the GitHub API as an alternative to the browser editor.
